Sistema de Agendamento

🌐 Acesse a aplicação: Clique aqui para visualizar o sistema

O Sistema de Agendamento é uma aplicação web desenvolvida para facilitar o agendamento e a consulta de compromissos de clientes. Possui uma interface simples e intuitiva, permitindo navegar entre as opções de agendamento e consulta da agenda.

Funcionalidades

Página inicial: apresenta as opções disponíveis no sistema.

Agendamento de clientes: permite realizar novos agendamentos.

Consulta de agenda: permite consultar os compromissos cadastrados.

Navegação: acesso às páginas por meio de um menu intuitivo.

Tecnologias utilizadas

HTML5

CSS3

JavaScript

Bootstrap 5.3.8

Interface

O sistema possui uma página inicial com acesso às funcionalidades de agendamento e consulta, além de páginas específicas para cada operação.

Como executar o projeto

Clone o repositório:

git clone URL_DO_SEU_REPOSITORIO

Acesse a pasta do projeto.

Abra o arquivo index.html no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão estática do projeto.

Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar conhecimentos em desenvolvimento Front-end, utilizando HTML, CSS e JavaScript para criar páginas web, organizar interfaces e implementar funcionalidades de navegação e agendamento.
